# ELFI DLLSCOPE — Windows System32 Forensic Scanner

An advanced digital forensics and malware-analysis utility developed by **ElfiZeroTrust**.

ELFI DLLSCOPE is designed to simplify the inspection of Windows System32 directories by automating the analysis of DLL files and their associated properties across multiple subdirectories.

Manually examining thousands of Windows system files can be extremely time-consuming. ELFI DLLSCOPE aims to make this process easier, faster and more organized by bringing system file inspection into a single forensic scanning workflow.

### Key Objectives

- Automated inspection of System32 subdirectories.
- DLL file identification and analysis.
- Collection of file properties and metadata.
- Assistance with identifying potentially suspicious system files.
- Simplified Windows system investigation.
- Support for digital forensics and malware-analysis workflows.

ELFI DLLSCOPE is intended for legitimate cybersecurity research, digital forensics and malware-analysis purposes. Findings should be treated as indicators for further investigation, not definitive proof of malicious activity.
